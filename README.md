🎬 Petflix – Netflix Clone (React + Vite)

A responsive Netflix-inspired web application built using React + Vite, styled with modern CSS and deployed on Netlify.
This project replicates the Netflix landing page UI with hero section, cards, and smooth layout flow.

🚀 Getting Started (Run Locally)
1️⃣ Clone the repository
git clone https://github.com/your-username/petflix-clone.git
cd petflix-clone

2️⃣ Install dependencies
npm install

3️⃣ Start development server
npm run dev


Open 👉 http://localhost:5173

📦 Build for Production
npm run build


Build output will be in the dist/ folder.

☁️ Deployment (Netlify)

Steps used to deploy:

Run npm run build

Upload dist/ folder to Netlify
OR

Connect GitHub repo → set:

Build command: npm run build

Publish directory: dist
